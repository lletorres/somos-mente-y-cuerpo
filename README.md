Somos Mente y Cuerpo - Plataforma Web
https://somosmenteycuerpo.com/

Este proyecto es el sitio web oficial de Somos Mente y Cuerpo (SMC), un equipo interdisciplinario con sede en Buenos Aires especializado en el tratamiento integral de Trastornos de la Conducta Alimentaria (TCA) y salud mental. La plataforma ofrece información sobre servicios clínicos, formación profesional y un canal de contacto directo para pacientes y familias.

🚀 Tecnologías Utilizadas
HTML5: Estructura semántica del sitio.

CSS3: Diseño personalizado, animaciones y responsive design (Mobile First).

JavaScript (Vanilla): Lógica de animaciones de scroll (Intersection Observer), manejo del menú móvil y transiciones de interfaz.

Google Fonts: Uso de las familias tipográficas Literata y Poppins.

🛠️ Características Principales
Diseño Interdisciplinario: Secciones dedicadas a psicología, psiquiatría, nutrición y clínica médica.

Responsive Design: Optimización completa para dispositivos móviles, tablets y ordenadores con ajustes específicos de visualización (ej. menú hamburguesa y grid adaptativo).

Sección de Formación: Catálogo de cursos para profesionales de la salud sobre terapias basadas en la evidencia como DBT, RO-DBT y CBT-E.

Interactividad:

Acordeones dinámicos para mostrar la formación detallada del equipo directivo.

Animaciones de entrada tipo "fade-in" al hacer scroll.

Indicador de sección dinámico en la barra de navegación para móviles.

Integración de Contacto: Enlace directo a WhatsApp para consultas inmediatas.

├── index.html           # Estructura principal del sitio

└── somos_mente_y_cuerpo.json # Especificaciones de diseño (Figma export)

🎨 Detalles de Diseño
Paleta de Colores: Basada en tonos suaves y profesionales:

Fondo principal: #fcfaf5.

Color acento (Rosa): #f79db9.

Color secundario (Violeta): #caacee.

Color terciario (Verde menta): #d3ede1.

Tipografía: Combinación de Literata para títulos (elegancia y lectura) y Lato/Aeonik para cuerpos de texto (claridad y modernidad).

🔧 Instalación y Despliegue
Clona el repositorio.

Asegúrate de que la carpeta assets contenga todas las imágenes y fuentes referenciadas en el CSS.

Abre index.html en cualquier navegador web moderno. No requiere compiladores externos ni dependencias de frameworks pesados.
